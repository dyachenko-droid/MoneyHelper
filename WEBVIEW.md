# Денежный помощник — WebView с нативными улучшениями

Ветка: `codex/webview`. Версия после переноса: **1.2.0 (3)**.

Внесены улучшения из `codex/native-only`, коммиты `6df8ab6` и `a7956c0`.
Коммит `8370814`, удалявший WebView, не переносился. Нативная ветка остаётся
на версии 1.1.0 (2). Контрольная точка WebView до переноса: `08b9a0c`.

`MainActivity`, `MoneyApp`, весь `data/domain/presentation/launch`, DI удалённого
старта, AndroidManifest и конфигурация SDK сохранены. Приложение продолжает
использовать `StartupGate`, AppsFlyer/Install Referrer, Firebase Realtime Database,
OneSignal external_id и WebView с загрузкой файлов. В нативном маршруте открывается
обновлённый `MoneyRoot` со всеми перечисленными ниже функциями.

## Улучшения в 1.1.0 (2)

1. Поиск включает категории частей операции, товары чека, заметку и оба счёта
   перевода. «Показать все операции» очищает поиск, месяц и остальные фильтры.
2. Над списком — итоги именно видимой выборки: количество, расходы, доходы и
   отдельная сумма переводов. При выборе счёта показаны входящие/исходящие переводы;
   дневной итог и изменение баланса учитывают направление. Перевод самому себе
   не изменяет баланс.
3. CSV: UTF-8/Windows-1251, ручной выбор кодировки и разделителя, кавычки,
   многострочный текст, строгие даты, точная десятичная арифметика до двух знаков.
   Отчёт считает все отклонения по причинам и показывает первые примеры строк.
   Совпадения проверяются внутри файла и на выбранном счёте; их пропуск можно
   отключить для разных покупок с одинаковыми датой, суммой и названием.
   Вставка всей выписки выполняется одной транзакцией. Максимальный CSV — 10 МБ.
   Восстановление CSV не равно полной копии: импорт пишет на выбранный счёт;
   переводы по умолчанию пропускаются, при отключении учитываются по знаку выписки.
4. Резервные копии: индикатор работы, защита от повторного нажатия, время последней
   успешной копии, ошибки без ложного сообщения об успехе. Новый `.backup` — ZIP
   со снимком SQLite и доступными фотографиями чеков. Снимок согласован транзакцией.
   Старые SQLite-копии версий 1/2 читаются после полной проверки целостности,
   структуры, типов, значений и связей. До подтверждения показана сводка, текущие
   данные не изменяются. Восстановление записей происходит одной транзакцией в
   работающей Room, без закрытия/подмены файла базы и перезапуска процесса.
   Перед заменой сохраняется внутренняя копия для отката; сбой до/во время записи
   оставляет текущие данные. Фотографии копируются в новые файлы, прежние не удаляются.
   Максимальная копия — 128 МБ, до 200 тысяч записей и 5000 фотографий; большие
   копии отклоняются до изменения данных. PIN, оформление и напоминания остаются
   текущими. Для новой копии проверяется совпадение валюты; старая копия без
   метаданных использует валюту текущих настроек. CSV сохраняет знак расходов < 1.
5. Карточка бюджета показывает регулярные платежи до конца месяца, остаток после
   них и доступную сумму на день. Учитываются все оставшиеся даты, в том числе
   несколько еженедельных платежей. Уже проведённый платёж сопоставляется по дате,
   счёту, сумме и названию, один к одному; он входит в расходы и повторно не
   резервируется. Это сопоставление по данным, поскольку старая схема не содержит
   идентификатора регулярного платежа в операции. Без лимита дневная сумма не
   показывается; при перерасходе она равна нулю, последний день считается одним днём.

Идентификатор пакета `ru.denpom.finance.app`, Room schema version 2 и DataStore
сохранены. Удалённый сценарий запуска остаётся прежним. В настройках отображается версия приложения.


## Проверки переноса

```sh
python3 scripts/check-bidi.py
JAVA_HOME='/Applications/Android Studio.app/Contents/jbr/Contents/Home' ./gradlew :app:testDebugUnitTest :app:assembleDebug :app:lintDebug :app:assembleDebugAndroidTest
```

Сохранены тесты удалённого старта и добавлены проверки нативной логики, CSV и
транзакционных резервных копий. `IsolatedTestRunner` использует отдельную Room в
памяти и обычный Application без AppsFlyer/OneSignal/фоновых инициализаторов.
Проверка Lint `BidiSpoofing`, зависающая в поставленной связке Kotlin 2.4 / lint
32.2.1, заменена отдельным `scripts/check-bidi.py`, как и в нативной ветке.
Остальные проверки Lint включены.

Подписанный релиз запускается прежним workflow `release.yml` для `codex/webview`.
Перед сборкой выполняются все JVM-тесты, Lint и проверка Unicode; ключи берутся
из repository secrets и не добавляются в исходники.
